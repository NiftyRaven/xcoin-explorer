XFER Explorer 1.1.0
A local website for X Coin (XFER) 1.0.13+
This is not a wallet. It cannot spend coins.

WINDOWS (double-click)
----------------------
1. Install Python 3.11+ from https://www.python.org/downloads/
   Tick "Add python.exe to PATH" on the first screen.
2. Install X Coin 1.0.13 (not 1.0.12 or older):
   https://github.com/NiftyRaven/x-coin/releases
3. Fully quit X Coin Wallet (tray icon -> Exit).
4. Open the folder that has "X Coin Wallet.exe".
   Open xcoin.conf in THAT folder (Notepad).
   Add this line if it is missing, then save:

   server=1

   1.0.13 reads this file when you double-click the wallet.
   Also add server=1 to %APPDATA%\XCoin\xcoin.conf if that file exists
   (Win+R -> %APPDATA%\XCoin).
5. Start X Coin Wallet.exe. Wait until it finishes loading.
6. In THIS explorer folder, double-click start.bat.
7. Browse http://127.0.0.1:8080

LINUX
-----
1. sudo apt install python3 python3-venv python3-pip
2. Install X Coin 1.0.13 from Releases (Linux x86_64 tarball).
3. Quit the wallet. Add server=1 to:
     - xcoin.conf next to the "X Coin Wallet" start, and
     - ~/.xcoin/xcoin.conf
4. Start X Coin Wallet, then in this folder:  chmod +x start.sh && ./start.sh

TEMPLATES (no secrets)
----------------------
  config/xcoin.conf.example     lines to add to the wallet
  explorer.toml.example         only if cookie login fails

Do not put rpcpasswords, .cookie, 12-word seeds, or API keys in git.
Copy explorer.toml.example to explorer.toml on YOUR machine only.
