XFER Explorer 1.2.0
A local website for X Coin (XFER) 1.0.13+
Blocks, assets, lottery, eligible @handles, and IPFS media.
This is not a wallet. It cannot spend coins.

ONE CLICK
---------
Windows:  double-click SETUP.bat
Linux:    chmod +x setup.sh && ./setup.sh

That script will:
  - install Python 3.11+ if needed
  - find or download official X Coin 1.0.13 (no keys in this zip)
  - add server=1 to the wallet config (no passwords)
  - start the wallet if it is not running
  - start this explorer at http://127.0.0.1:8080

Finish any first-run 12-word screen in the wallet window, then wait.
If the browser does not open, go to http://127.0.0.1:8080 yourself.

Already set up? Double-click start.bat  (Windows)  or  ./start.sh  (Linux).

MANUAL (if one-click cannot run)
--------------------------------
Windows
  1. Install Python 3.11+ from https://www.python.org/downloads/
     Tick "Add python.exe to PATH" on the first screen.
  2. Install X Coin 1.0.13 (not 1.0.12):
     https://github.com/NiftyRaven/x-coin/releases
  3. Fully quit X Coin Wallet (tray icon -> Exit).
  4. Add this line to xcoin.conf NEXT TO "X Coin Wallet.exe"
     and to %APPDATA%\XCoin\xcoin.conf if that file exists:

     server=1

  5. Start X Coin Wallet.exe. Wait until it loads.
  6. Double-click start.bat
  7. Browse http://127.0.0.1:8080

Linux
  1. sudo apt install python3 python3-venv python3-pip
  2. Install X Coin 1.0.13 (Linux x86_64 tarball) from Releases.
  3. Add server=1 next to "X Coin Wallet" and in ~/.xcoin/xcoin.conf
  4. Start the wallet, then:  chmod +x start.sh && ./start.sh

TEMPLATES (no secrets)
----------------------
  config/xcoin.conf.example     lines to add to the wallet
  explorer.toml.example         only if cookie login fails

Do not put rpcpasswords, .cookie, 12-word seeds, or API keys in git.
Copy explorer.toml.example to explorer.toml on YOUR machine only.
